# หมากรุกไทย · Makruk

Thai chess for the web: play the computer, play online or pass-and-play on one
device, and learn with bite-sized lessons.

Live: https://th-chess.beanroti.com (in development)

## Develop

```bash
nvm use
./init.sh        # install + verify
npm run dev      # web on http://localhost:5173, worker on :8787
```
